# Invitación de boda

Nueva versión de la invitación creada con Next.js, React, TypeScript y
Tailwind CSS.

## Desarrollo local

```bash
npm install
npm run dev
```

## Estructura inicial

- `app/`: página principal, metadata y estilos globales.
- `components/`: secciones reutilizables de la invitación.
- `public/`: imágenes, audio y demás archivos estáticos.

La información que aparece actualmente es provisional. La siguiente etapa será
migrar el contenido, las imágenes y las funciones de la invitación original.
